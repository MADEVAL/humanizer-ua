# Eval

Мінімальний набір перевірок, який не потребує моделей, мережі й ключів.

## Що перевіряється

1. **Розділення корпусу.** Сканер має ставити AI-текстам нижчий бал, ніж людським.
2. **Кейси.** Для кожної пари «оригінал → чистовик» перевіряється, що обов'язкові факти на місці, а зайвих немає.
3. **Факт-замок.** Числа, дати, цитати й імена не зникають.

Це **не** доказ якості на будь-якому тексті. Це регресійний тест: він ловить грубі поломки правил і прикладів.

## Запуск

```bash
python eval/run_eval.py
```

Очікуваний результат:

```
РЕЗУЛЬТАТ: ПРОЙШЛО
```

Код виходу 1 — є провал; деталі друкуються під заголовком «ПРОВАЛ».

## Структура

```
eval/
├─ corpus/
│  ├─ ai/       # тексти з маркерами
│  └─ human/    # природні тексти
├─ cases.jsonl  # пари «було → стало»
├─ rubric.md    # рубрика для LLM-судді
└─ run_eval.py
```

## Як додати кейс

Додай рядок у `cases.jsonl`:

```json
{"id": "case-11-...", "genre": "marketing", "before": "...", "after": "...", "must_keep": ["40 %"], "must_not_add": ["45 %"], "note": "..."}
```

Поля:

- `id` — унікальний;
- `genre` — один із жанрів сканера;
- `before`, `after` — тексти;
- `must_keep` — рядки, які мусять бути в `after` (перевірка чутлива до регістру);
- `must_not_add` — рядки, яких не має бути;
- `note` — що саме демонструє кейс.

## Як додати корпус

- `corpus/ai/` — текст із 3+ маркерами, бажано різних груп.
- `corpus/human/` — текст, написаний людиною без навмисного стилю «під ШІ».
- Не додавай тексти, захищені авторським правом, без дозволу. Пиши свої.
- Не додавай тексти з персональними даними.

## Межі

- Корпус маленький і нерепрезентативний.
- Сканер евристичний: він не розуміє іронію, цитати й контекст.
- Бал не є ймовірністю ШІ.
- Eval не перевіряє голос і естетику. Для цього — `rubric.md` і людська вибірка.

## Розширення

Коли з'явиться більший корпус:

1. Додай `corpus/humanized/` — тексти, відредаговані скілом.
2. Порахуй середній бал до/після.
3. Перевір, чи не впав факт-замок.
4. Додай blind A/B за `rubric.md`.
5. Опублікуй метод і обмеження, а не лише результат.
