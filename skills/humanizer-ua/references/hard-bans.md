# Жорсткі заборони

30 конструкцій і 15 нормативних ID (11 правил реалізовано, `N09–N12` — аліаси), які знімаються в будь-якому режимі, крім жанрів, позначених у колонці «Не в». Повний каталог пояснює, чому вони погані; ця таблиця — операційний список для правки й сканера.

**Як користуватися:**

1. Скан зверху вниз: спершу `HB01–HB15` (порожня риторика), потім `HB16–HB30` (лексика й канцелярит).
2. Кожну фразу замінюй **не іншою ефектною фразою**, а видаленням або перебудовою з тих самих слів.
3. Не застосовуй до цитат, назв, посад, продуктів і прямої мови.
4. Якщо фраза стоїть у реченні, яке цитує джерело, — це цитата, не заборона.

## Нормативний шар

Ці правила не залежать від жанру й не бувають «слабким сигналом». Нормативна помилка — привід не публікувати, доки її не виправлено.

| ID | Що перевіряти | Приклад | Серйозність |
|---|---|---|---|
| **N01** | Дефіс замість тире | `це - помилка` → `це — помилка` | error |
| **N02** | Екранований, HTML або ASCII апостроф | `з\’єднання`, `об'єкт` → `з’єднання`, `об’єкт` | error |
| **N03** | Лапки не «» | `"текст"` → `«текст»` | error |
| **N04** | Пробіл перед розділовим знаком | `слово ,` → `слово,` | error |
| **N05** | Подвійний пробіл | `два  пробіли` → `два пробіли` | error |
| **N06** | Число й одиниця без пробілу | `30%`, `2МБ`, `2026р.` → `30 %`, `2 МБ`, `2026 р.` | error |
| **N07** | Діапазон через дефіс | `10-20` → `10–20` | error |
| **N08** | Нерозривний пробіл не на місці | `текст\u00a0 .` → звичайний пробіл | error |
| **N09** | Русизми й суржик | `привносити`, `відноситися`, `получати` | error |
| **N10** | Прийменникові кальки | `по питанню`, `в якості`, `на протязі` | error |
| **N11** | Милозвучність `в/у`, `і/й`, `з/із/зі` | `вона і він` → `вона й він` | warning |
| **N12** | Керування відмінками | `дякуючи підтримки` → `завдяки підтримці` | error |
| **N13** | Російські літери | `ё`, `ы`, `э`, `ъ` | error |
| **N14** | Повтор слова в реченні | `сайт … сайт` | warning |
| **N15** | Змішані алфавіти в слові | `WоrdPress` з кириличною `о` | error |

`N09–N12` уже закриті правилами `C1`, `HB19–HB23`, `HB20`, `G1`, `HB22`: окремих реалізацій немає, щоб один дефект не штрафувався двічі.

## Порядок зняття

1. **HB13, HB14, HB15** — прибрати постановку. Після цього часто стає видно, що текст коротший, ніж здавався.
2. **HB02, HB03, HB12** — прибрати підводки й переходи.
3. **HB04, HB05, HB19–HB23, HB27, HB28** — виправити мову.
4. **HB06–HB11, HB17, HB18, HB24–HB26, HB29, HB30** — замінити роздуті формули конкретикою.
5. **HB01, HB16** — перевірити початок і філер.

## Межі

- Заборона діє на **використання**, не на згадку. «У статті розглядається термін «являється»» — не порушення.
- Заборона не скасовує факт-замок. Якщо джерело каже «може», чистовик не робить «робить».
- Заборона не дозволяє дописувати. «Комплексний підхід» без переліку складників стає не «ще кращим комплексним підходом», а видаляється.
- У юридичному тексті заборона не застосовується, якщо формула має юридичну силу. Тоді виправляй лише явні мовні помилки.
- У художньому тексті суржик і штампи можуть бути голосом персонажа. Не чіпай репліки.

## Сканер

`scripts/scan.py` реалізує `HB01–HB30`, нормативні `N01–N08`, `N13–N15` і 33 маркери каталогу. Решта 47 записів — ручний чекліст редактора. Правила з жанровими винятками позначені в `scripts/humanizer_ua/rules.py` і `norm.py`. Сканер — це фільтр, а не редактор: він знаходить збіги, а рішення ухвалює людина або агент у контексті.

**Три шкали.** `норма` (N і мовні HB) відповідає на питання «чи можна це публікувати». `стиль` — «чи варто це переписати». `структура` — «чи не шаблон це». Підсумкова «чистота» — зважене геометричне середнє за профілем жанру, і норма має вето: текст із помилкою не стає «чистим» навіть із ідеальним стилем.

**Плотність.** Штраф рахується за подіями на 1000 слів, а не за кожним словом. Одне правило не може обнулити текст; десять різних — можуть. Слабкі сигнали штрафуються лише в компанії іншого маркера в тому самому абзаці.
