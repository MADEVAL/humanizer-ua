# Сканер

Детермінований сканер — машинна половина аудиту. Він не редактор і не детектор ШІ: він знаходить передбачувані звороти, метрики й розбіжності у фактах.

## Запуск

```bash
# файл
python3 <папка скіла>/scripts/scan.py стаття.txt

# stdin
cat стаття.txt | python3 <папка скіла>/scripts/scan.py -

# жанр
python3 <папка скіла>/scripts/scan.py стаття.txt --genre academic

# порівняння з оригіналом
python3 <папка скіла>/scripts/scan.py стало.txt --before було.txt

# JSON для інтеграції
python3 <папка скіла>/scripts/scan.py стаття.txt --json

# CI-гейт: код 1, якщо нижче порогу
python3 <папка скіла>/scripts/scan.py стаття.txt --min-score 60

# Кілька файлів або тека
python3 <папка скіла>/scripts/scan_gate.py статті/ --min-score 60

# Кодування (типово auto: UTF-8, потім Windows-1251)
python3 <папка скіла>/scripts/scan.py стаття.txt --encoding cp1251
```

**Залежності:** лише стандартна бібліотека Python 3.9+. Ні `pip install`, ні моделей, ні мережі.

## Жанри

| Прапорець | Що робить |
|---|---|
| `marketing` (типово) | Усі правила |
| `expert` | Пом'якшує частину лексичних правил |
| `business` | Лишає формальний регістр |
| `news` | Вимкняє частину канцеляриту й пасиву |
| `academic` | Вимкняє канцелярит, пасив, «даний», «являється» |
| `legal` | Лишає майже всі формули |
| `docs` | Не чіпає терміни й код |
| `fiction` | Вимкняє стилістичні правила, лишає обгортку чату й мовні помилки |

Правила з винятками описані в `scripts/humanizer_ua/rules.py` і `hard-bans.md`.

## Що виводить

```
ЧИСТОТА: 42/100  [маркетинг] · правка
  -24  жорсткі заборони: 3
  -18  маркери: 6 (2.4/100 слів)
  -8   метрики: 2
  -8   факт-замок
  слабких без штрафу: 1
  слів: 180

ЖОРСТКІ ЗАБОРОНИ:
  ⛔ HB01 «У сучасному світі» ×1 (рядок 1)
  ⛔ HB05 «Являється» ×1 (рядок 4)

МАРКЕРИ:
  • A1 «Не просто X, а Y» ×1 (рядок 2)
  • C1 «Русизм» ×1 (рядок 6)
  • C11 «Розмитий зв'язок» ×1 (рядок 8, слабкий, без штрафу)

МЕТРИКИ:
  • Багато тире: 4 (норма до 1.5) — 4 на 180 слів
  • Болд-декор: 6 (норма до 2.4) — 6 виділень

ФАКТ-ЗАМОК:
  втрачено: 40 %
  втрачено: Олена Коваль
  додано: 25 %
  квантор: перший
  оговорка: може
  розмітка: заголовок 3→2
```

`ЧИСТОТА` — це 100 мінус штрафи за правилами. Це **не** ймовірність ШІ й **не** оцінка авторства. Слабкі маркери (`HB16`, `C9`, `C11`, `D8` та інші) штрафуються лише тоді, коли в тому самому абзаці є ще один маркер.

## Коди виходу

| Код | Значення |
|---|---|
| 0 | Успіх; поріг не заданий або пройдений |
| 1 | Бал нижче `--min-score` |
| 2 | Помилка читання або аргументів |

## Як читати метрики

| Метрика | Норма | Що робити |
|---|---|---|
| Тире | ≤ 1 на 120 слів | Прибрати зайві, не всі |
| Болд | ≤ 2 на 500 слів | Прибрати декор |
| Емодзі | 0 у службовому тексті | Прибрати |
| Однотипні початки | ≤ 2 підряд | Об'єднати або змінити підмет |
| Рівномірна довжина | CV ≥ 0.30 | Перевірити ритм очима |
| Рівні абзаци | CV ≥ 0.30 | Дати абзацам різну довжину |
| Обірвані речення | без ланцюгів 3+ | Прибрати штучну «рваність» |
| Номіналізації | ≤ 8 на 100 слів | Розгорнути в дієслова |
| Пасив | ≤ 10 на 100 слів | Назвати діяча |
| «Який» | ≤ 4 на 100 слів | Розбити ланцюг |
| Повтор фраз | 0 повторів | Лишити фразу в одному місці |

Це орієнтири, не догми. Текст із одним тире й трьома «який» може бути чудовим.

## Факт-замок

З `--before` сканер витягує з оригіналу й чистовика:

- числа, величини з одиницями, відсотки, валюти, масштаби (`млн`, `млрд`, `тис`);
- дати й назви місяців;
- числа словами (`п'ять`, `тисяча`);
- власні назви (евристика за великою літерою; латиниця — теж ім'я);
- посилання, inline-код і цитати;
- квантори: «перший», «єдиний», «вперше», «рекордний», «найбільший»;
- оговорки: «може», «часто», «приблизно», «до», «від», «лише», «якщо», «ризик»;
- розмітку: заголовки, пункти списків, рядки таблиць;
- виділення: жирний, курсив.

Порівнює множини й показує втрачене/додане. Це евристика: вона може пропустити перефразоване число, хибно позначити власну назву або не зрозуміти заперечення. Остаточне рішення — за редактором.

**Квантори окремо.** «Перший в Україні» — це факт, а не пафос. Якщо чистовик його втратив, поверни. Якщо додав — перевір, чи це не вигадка.

**Що робити з «втрачено»:** поверни факт у чистовик, якщо він справді був у джерелі. Якщо факт був зайвий і його видалено навмисно — це не помилка, але познач у звіті.

## Якщо сканер недоступний

1. Скажи про це, лише якщо користувач просив бал або аудит.
2. Пройди `hard-bans.md` очима.
3. Порахуй маркери вручну за каталогом (приблизно).
4. Перевір факти за `review.md`.
5. Не вигадуй бал. Напиши «балу немає».

## Обмеження

- Не розуміє іронію, цитати, контекст, намір.
- Не відрізняє ШІ від людини.
- Не знає всіх діалектів і професійних жаргонів.
- Не бачить смислових помилок, якщо слова правильні.
- Не замінює читання. Сканер — це чекліст, а не редактор.

## Для розробників

- `scripts/humanizer_ua/text.py` — читання, маскування, абзаци.
- `scripts/humanizer_ua/rules.py` — таблиці правил.
- `scripts/humanizer_ua/markers.py` — зіставлення й слабкі сигнали.
- `scripts/humanizer_ua/metrics.py` — ритм, структура, оформлення.
- `scripts/humanizer_ua/facts.py` — факт-замок.
- `scripts/humanizer_ua/score.py` — бал і звіт.
- `scripts/humanizer_ua/cli.py` — CLI.
- `scripts/test_scan.py`, `scripts/test_rules.py` — тести.
- `scripts/scan_gate.py` — CI-гейт по файлах.
- `scripts/lint_skill.py`, `scripts/check_examples.py`, `scripts/install_smoke.py` — QA пакета.
- `eval/run_eval.py`, `eval/run_triggers.py` — eval і покриття опису.

Додаєш правило — додай тест і запис у `CHANGELOG.md`. Не додавай правило, яке не можна пояснити одним реченням.
