# Перегріті слова й кліше

Слово саме по собі не заборонене. Воно стає маркером, коли замінює доказ, число або конкретну дію. Терміни в `docs`, `academic` і `legal` лишай, якщо вони мають усталене значення.

**Правило:** не шукай синонім — шукай факт. «Ефективний» не стає кращим від «результативний», якщо немає мірила.

## Оцінка без доказу

| Слово | Що робити |
|---|---|
| ключовий | Назви, для чого саме ключовий, або прибери |
| важливий | Скажи, що зміниться, якщо це проігнорувати |
| унікальний | Назви ознаку, якої немає в інших |
| інноваційний | Скажи, що нового й порівняно з чим |
| ефективний | Дай мірило: час, гроші, кількість |
| оптимальний | Назви критерій оптимальності |

| сучасний | Скажи, коли й що саме |
| актуальний | Для кого, коли й чому |
| значущий | Назви наслідок |
| стратегічний | Назви мету й горизонт |
| динамічний | Скажи, що змінюється і як швидко |
| багатогранний | Перелічи грані |
| всебічний | Перелічи, що охоплено |
| цілісний | Перелічи складники |
| гнучкий | Скажи, як налаштовується |

## Метафори-пустушки

| Формула | Що робити |
|---|---|
| відкриває нові горизонти | Назви результат |
| виводить на новий рівень | Назви, що змінилося |
| є невід'ємною частиною | «Входить до» |
| відіграє важливу роль | Скажи, що саме й для чого |
| стає справжнім проривом | Скажи, що стало можливим |
| у світі, що стрімко змінюється | Прибери або назви зміну |
| на часі | Скажи, чому саме тепер |
| не має аналогів | Назви, з чим порівнювали |
| говорить сам за себе | Назви, що саме він показує |

## Як користуватися

1. Знайди слово з таблиці.
2. Спитай: «Що тут можна перевірити або порахувати?»
3. Якщо відповідь є в тексті — заміни слово фактом.
4. Якщо відповіді немає — прибери слово або залиш просте твердження.
5. Не додавай факт, якого немає в джерелі. Порожнє місце краще за вигадане число.

**Не роби з цього чорний список.** «Ключовий» у технічному тексті («ключовий файл», «ключовий кадр») — термін. «Важливий» у листі може бути нормальною ввічливістю. Дивись на функцію слова, а не на саме слово.
