# Humanizer-UA

Скіл для редагування українського тексту: прибирає сліди ШІ, канцелярит, суржик, русизми й кальки, не змінюючи зміст, факти та голос автора.

[github.com/MADEVAL/humanizer-ua](https://github.com/MADEVAL/humanizer-ua) · автор: [Yevhen Leonidov](https://github.com/MADEVAL)

Не детектор ШІ. Не генератор «живішого» тексту. Редактор, який видаляє обгортку, а не дописує поверх неї.

## Ідея

Модель пише те, що найімовірніше підійде найширшому читачеві. Людина пише для одного читача й однієї ситуації. Звідси всі маркери: постановка замість твердження, тріади за правилом, роздута значущість, декор, залишки чату.

Український текст має ще один шар — **російський синтаксис**. «Являється», «на протязі», «в якості», «приймати участь», «діючий закон», «згідно наказу». Це не стилістична дрібниця, а найпомітніша ознака машинного тексту для українського читача. Тому в скілі є окремий словник замін, ширший за список «AI-слів».

## Що робить

- Знімає 63 маркери у восьми групах: постановка, ритм, лексика, формат, залишки чату, сенс, українська норма, дискурс.
- Тримає **факт-замок**: числа, величини, дати, імена, цитати, квантори, оговорки, розмітка й модальність не змінюються.
- Працює локально: правка конкретних місць, а не переписування з нуля.
- Враховує жанр: маркетинг, експертиза, лист, новини, наука, документація, юридика, художній текст.
- Має детермінований сканер без залежностей: 30 заборон, 21 маркер, метрики ритму й структури.
- Не штрафує слабкий маркер, якщо в абзаці немає інших ознак.
- Має eval-корпус, рубрику, перевірку тригерів і CI-гейт.


```
[встав текст]
```

Або звичайною мовою: «очеловеч цей текст», «прибери сліди ШІ», «вичитай і прибери канцелярит», «зроби живішим, але нічого не додавай».

### Сканер

```bash
python3 skills/humanizer-ua/scripts/scan.py стаття.txt --genre marketing
python3 skills/humanizer-ua/scripts/scan.py стало.txt --before було.txt
```

Лише стандартна бібліотека Python 3.9+. Без `pip install`, моделей і мережі.

## Режими

| Режим | Коли | Результат |
|---|---|---|
| **Редактура** | «очеловеч», «перепиши», «вичитай» | Чистовик + 1–2 рядки |
| **Аудит** | «перевір», «знайди маркери» | Звіт, текст не змінюється |
| **Точкова правка** | «прибери тільки канцелярит» | Лише названа категорія |
| **Власна чернетка** | без прохання, мовчки | Агент перевіряє власний український текст; чужий не чіпає |
| **Голос за зразками** | автор дав 2–3 тексти | Профіль голосу, заміни в його межах |

Сказав «не прав» — режим «Власна чернетка» вимкнено до кінця розмови.

## Приклад

**Було:**

> У сучасному світі спільна робота над документами відіграє ключову роль. Варто зазначити, що даний інструмент являється комплексним рішенням, яке відкриває нові горизонти. Ми запустили спільні чернетки: двоє людей можуть редагувати документ одночасно, зміни видно одразу. Коментарі залишаються прив’язаними до речення.

**Стало:**

> Ми запустили спільні чернетки. Двоє людей можуть редагувати документ одночасно, зміни видно одразу. Коментарі залишаються прив’язаними до речення.

Знято шість жорстких заборон і одну підводку. Нового факту не додано.

**Аудит того самого тексту:**

```
ЧИСТОТА: 44/100  [marketing] · рерайт
  -56  жорсткі заборони: 6
  слів: 40

ЖОРСТКІ ЗАБОРОНИ:
  ⛔ HB01 «У сучасному світі» ×1 (рядок 1)
  ⛔ HB02 «Варто зазначити» ×1 (рядок 1)
  ⛔ HB04 «Даний / дана / дане» ×1 (рядок 1)
  ⛔ HB05 «Являється» ×1 (рядок 1)
  ⛔ HB06 «Відіграє роль» ×1 (рядок 1)
  ⛔ HB08 «Нові горизонти» ×1 (рядок 1)
```

Бал — це правила сканера, не ймовірність ШІ й не вирок про авторство.

## Як працює

```
0. Межі         → що можна чіпати, що ні
1. Діагностика  → сканер + читання цілком
2. Розмітка     → KEEP / CUT / TRIM / REPLACE / JOIN / SPLIT
3. Правка       → жорсткі заборони → A–H
4. Факт-замок   → числа, імена, умови, модальність
5. Свіжа вичитка→ незалежний рев'ю
6. Повторний скан → два кола максимум
7. Видача       → текст, максимум два рядки службового
```

**Головне правило:** видаляй, не дописуй. Емоції, оцінки, жарти, образи й факти, яких немає в джерелі, не додаються.

## Принципи

1. **Видаляй, не дописуй.** Маркер знімається видаленням обгортки або перебудовою з тих самих слів.
2. **Факт-замок сильніший за стиль.** Втрачене число — провал, навіть якщо текст звучить краще.
3. **Локальна правка.** Не переписуй структуру, якщо проблема в одному реченні.
4. **Жанр визначає межі.** Те, що вада в блозі, може бути нормою в науці чи юридиці.
5. **Одна ознака — не маркер.** Маркер — це щільність і автоматичність.
6. **Не детектор.** Скіл не обіцяє проходження AI-детекторів і не вставляє одруки.
7. **Голос автора — частина змісту.** Не вирівнюй живий текст під «ідеальний».

## Eval

```bash
python eval/run_eval.py
```

Перевіряє:

- AI-тексти отримують нижчий бал, ніж людські;
- кейси зберігають обов'язкові факти;
- факт-замок не вважає втраченим те, що мусить залишитися.

Поточний корпус маленький: 3 AI-тексти, 2 людські, 10 кейсів. Це регресійний тест, а не доказ якості на будь-якому тексті.
